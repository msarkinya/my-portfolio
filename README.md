# Maryam Saidu Sarkin'ya — Portfolio (GitHub Pages ready)

This repository is a simple HTML/CSS portfolio site designed for GitHub Pages.

## How to deploy
1. Create a new **public** repository on GitHub named `maryam-portpolio`.
2. Upload the contents of this ZIP (all files and the `assets/` folder) into the repository root.
3. In the repository, go to **Settings → Pages** and select the **main** branch (or `gh-pages` if you create one) and `/ (root)` as the folder. Save.
4. Your site will be available at: `https://msarkinya.github.io/maryam-portpolio/` (it may take a minute to publish).

If you prefer, you can also deploy using the command line:
```bash
git init
git add .
git commit -m "Initial portfolio site"
git branch -M main
git remote add origin https://github.com/msarkinya/maryam-portpolio.git
git push -u origin main
```
